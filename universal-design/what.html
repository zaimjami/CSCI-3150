Principles

Universal design applies the WCAG framework in a product mindset: interfaces must be Perceivable, Operable, Understandable, and Robust.

Perceivable

  • Provide text alternatives for non-text media (alt text, captions, transcripts).
  • Use sufficient color contrast and never rely on color alone for meaning.
  • Respect user font size and motion preferences.

Operable

  • All functionality via keyboard; visible focus indicators everywhere.
  • Logical tab order and skip navigation.
  • Touch targets sized ~44–48px with comfortable spacing.

Understandable

  • Predictable navigation and labels; descriptive link text.
  • Helpful form guidance, error prevention, and clear messages.
  • Readable type scale and generous line-height/spacing.

Robust

  • Semantic HTML with proper landmarks and headings.
  • ARIA only when native semantics can’t express the role/state.
  • Test with multiple AT, browsers, and devices.

Patterns that scale

  • Semantic navigation (header/nav/main/aside/footer)
  • Responsive grid/flex layouts
  • Accessible media (alt, captions, transcripts)
  • Resilient forms and tables
