Core patterns

Landmarks & headings

  • One <main> per page; consistent <header>, <nav>, <footer>, and meaningful <aside>.
  • Heading order is hierarchical: H1 → H2 → H3 (no jumps).
  • Every section has a titled heading (no “untitled” outline nodes).

Keyboard & focus

  • Everything is reachable via keyboard (Tab/Shift+Tab/Enter/Space/Arrows/Esc).
  • Visible focus ring on all interactive elements.
  • Skip link is the first focusable control and lands in #main.

Contrast, sizing, and motion

  • Text contrast ≥ WCAG AA; never encode meaning by color alone.
  • Touch targets ~44–48px with adequate spacing.
  • Respect prefers-reduced-motion and user font size.

Forms & tables

  • Explicit <label for>, helpful hints, clear errors.
  • Table <caption>, <thead>/<tbody>/<tfoot>, correct header scope.

Testing workflow

  1. Validate HTML with the Nu Validator.
  2. Run WAVE (0 errors; check contrast).
  3. Open Lighthouse → Accessibility (90+ is the floor, aim for 100).
  4. Check the HTML5 Outliner (no untitled sections).
  5. Keyboard test end-to-end; then try a screen reader (VoiceOver/NVDA).

Example: skip link + focus style

<a class="skip-link" href="#main">Skip to content</a>

.skip-link{
  position:absolute; left:0; top:-40px;
  background:#000; color:#fff; padding:.5rem .75rem; border-radius:.25rem;
}
.skip-link:focus{ top:0 }

Ship checklist

  • Semantic landmarks present
  • Headings structured
  • Keyboard complete + visible focus
  • Contrast passes
  • Media has text alternatives
  • Validated (Nu, WAVE, Lighthouse, Outliner)
