How to build it (copy-paste patterns)

1) Focus you can actually see

/* WCAG 2.2-friendly focus ring */
:where(a, button, input, select, textarea):focus-visible{
  outline: 3px solid #e9c46a;   /* high-contrast */
  outline-offset: 2px;
  border-radius: .25rem;
}

Meets the “change of contrast + area” intent in Focus Appearance (Minimum).

2) Thumbable target sizes

/* 44x44 CSS px minimum target area via padding */
.nav a{
  display:inline-flex; align-items:center; gap:.35rem;
  min-height: 44px; min-width: 44px; padding: .6rem .85rem;
}

Aligns to WCAG 2.2 Target Size (Minimum) with spacing exceptions where applicable.

3) Robust forms

<fieldset>
  <legend>Contact Info</legend>
  <label for="fn">Full name</label>
  <input id="fn" name="name" autocomplete="name" required>

  <label for="email">Email</label>
  <input id="email" type="email" name="email"
         autocomplete="email" inputmode="email" required
         aria-describedby="email-help">
  <p id="email-help">We'll only use this to reply.</p>
</fieldset>

Uses native validation UI + programmatic help via aria-describedby.

4) Disclosure (show/hide) per APG

<details class="faq">
  <summary>What is universal design?</summary>
  <p>Design that works for everyone by default.</p>
</details>

Prefer native <details>/<summary>; for custom widgets follow APG keyboard patterns.

5) Respect reduced motion

@media (prefers-reduced-motion: reduce){
  *{ animation-duration: .001ms !important; animation-iteration-count: 1 !important; transition-duration: 0s !important; }
}

Prevents vestibular triggers while preserving function.

6) Accessible math (native)

<math display="block">
  <msup><mi>a</mi><mn>2</mn></msup>
  <mo>+</mo>
  <msup><mi>b</mi><mn>2</mn></msup>
  <mo>=</mo>
  <msup><mi>c</mi><mn>2</mn></msup>
</math>

Leverages MathML Core; assistive tech can navigate/read structure without extra JS.

Quick QA loop

  1. Tab through every control—can you always see focus?
  2. Try keyboard-only: can you open menus, activate tabs, submit forms?
  3. Run WAVE and Nu; fix errors (contrast, missing labels, headings).
